# Claim

A robust chunk-claiming mod for Minecraft.

## Features
- **Chunk-based Claiming**: Secure land by chunks using `/claim`.
- **Protection**: Prevents unauthorized block breaking, placing, and interaction.
- **Admin Bypass**: Administrators can manage any claim.
- **Persistence**: Claims are saved between server restarts.

## Commands
- `/claim`: Claim the current chunk.
- `/claim unclaim`: Unclaim the current chunk.
- `/claim info`: View owner information for the current chunk.
- `/claim admin unclaim`: Force unclaim a chunk (Admins only).
